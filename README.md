# Spring JDBC Practice

This repository contains a simple Java project demonstrating **Spring JDBC** for basic CRUD operations using:

- `BasicDataSource` for database connection management
- `JdbcTemplate` for executing SQL queries
- Java-based configuration (no XML)
- A simple DAO (Data Access Object) layer

The project is intended for beginners who want to understand how Spring JDBC works without Spring Boot or ORM frameworks like Hibernate.

---

## Features

- Create, Read, Update, Delete (CRUD) operations on a sample `student` table
- Plain Spring JDBC setup without Spring Boot
- Java-based configuration for `DataSource` and `JdbcTemplate`
- Easy-to-understand DAO implementation

---

## Technologies Used
  
- Spring JDBC  
- Apache Commons DBCP (`BasicDataSource`)  
- MySQL (or any relational DB of your choice)  
- Maven for dependency management
